Compact 0.23 • Midnight ZK-SNARK Engine

Modular AI & Zero-Knowledge
Verification Platform

ProofShield combines deterministic data normalization with Midnight's Compact smart contract framework to verify complex technical competence without leaking personal or proprietary data.

<

1. Evidence Layer

Ingests heterogeneous technical activity from GitHub, Hack The Box, TryHackMe, and certifications. Data is scrubbed locally so raw credentials, commit histories, and personal identifiers never touch the network.

*

2. ZK Prover Engine

Executes client-side Compact circuits (k=7 and k=9) through Midnight's Proof Server. Synthesizes cryptographic witnesses that prove mathematical satisfaction without disclosing raw variables.

#

3. Ledger Settlement

Publishes only the immutable verification outcome (claim_verified = true) to the Midnight blockchain. Verifiers confirm cryptographic validity without storing or observing candidate data.

Compact Circuit Architecture

Every claim in ProofShield is expressed as a mathematical circuit in Compact. Public parameters are stored on the ledger, while private witnesses remain strictly off-chain:

pragma language_version 0.23; // PUBLIC LEDGER STATE (On-Chain, Verified by Consensus) export ledger claim_verified: Boolean; export ledger threshold: Uint<64>; // CIRCUIT: Set the public benchmark export circuit initialise_claim(required_count: Uint<64>): [] { threshold = disclose(required_count); claim_verified = disclose(false); } // CIRCUIT: Verify candidate qualification (PRIVATE WITNESS) export circuit submit_proof(activity_count: Uint<64>): [] { const passes: Boolean = activity_count >= threshold; claim_verified = disclose(passes); }

Enterprise Security Guarantees

• Zero PII Exposure: No emails, repository URLs, or full names stored on-chain.
• Tamper-Proof Ledger: Built on Midnight's dual-state Substrate consensus.
• Deterministic Normalization: Code analysis runs locally before circuit synthesis.

Circuit Specifications

• initialise_claim: k = 7, 90 constraint rows.
• submit_proof: k = 9, 123 constraint rows.
• Prover Latency: < 120ms local synthesis via Proof Server.
